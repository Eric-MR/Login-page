# Login-page
Current Status

The project currently includes: A basic structure for a login page Initial backend functionality for handling user data The focus at this stage is functionality, clean code, and backend skill development.

Planned Features Future updates will include, among others: Registration page Security checks, such as: XSS protection SQL/code injection prevention Secure password handling (hashing, salting) Role and permission management Extended server-side validation Optional API integration The project is open-ended, allowing plenty of room for new ideas and improvements.

Contributions & Feedback

Everyone is welcome to share tips, tricks, ideas, or improvements. Please keep feedback: constructive,respectful,no hate. Even small suggestions or code optimizations are appreciated.

Technologies (current / planned) Backend: Flask Frontend: ? Database: MySQL

Project Goal

The goal is to build a clean, secure, and modular login system, allowing me to gradually expand my backend knowledge—from basics to professional security standards.
